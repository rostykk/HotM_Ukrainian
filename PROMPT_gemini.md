# Переклад батчів через Gemini

Claude бере батчі з початку раунду, Gemini з кінця, і ви сходитеся посередині.

Команди запускаються з активованим `.venv` (див. «Середовище» в `README.md`).

## 1. Взяти батчі (з кінця)

```
python hotm_uk.py claim gemini 5 --from-end
```

Команда покаже, які файли перекладати (`batches\r01\NNN.json`) і куди класти відповідь (`batches\r01\out\NNN.json`).
Номер файлу відповіді має **збігатися** з номером батчу.

## 2. Промпт

Додайте до чату `STYLE_uk.md` (один раз на чат) і файл батчу, потім вставте:

```
Ти — професійний локалізатор відеоігор англійською→українською.
Переклади доданий JSON-батч гри Heart of the Machine.
Дотримуйся стильового посібника STYLE_uk.md і поля "instructions" у батчі.
Терміни з поля "glossary" обов'язкові (відмінюй їх за потреби).
Збережи {плейсхолдери}, <теги>, кількість переносів рядків \n і пробіли на початку/в кінці.
Поверни ЛИШЕ JSON-об'єкт {"1": "переклад", "2": "...", ...} для кожного id, без пояснень.
```

Якщо відповідь обірвалася (дуже довгий батч), напишіть «продовж з id N» і склейте шматки в один JSON.
Можна й так: імпортувати неповну відповідь, а пропущені рядки потраплять у наступний `export`.

Gemini CLI (якщо користуєтесь ним) приймає файли через `@шлях`, тоді відповідь можна одразу записати у файл, наприклад:

```
gemini -p "@STYLE_uk.md @batches/r01/125.json <промпт вище>" > batches/r01/out/125.json
```

## 3. Перевірка (необов’язково, але корисно)

```
python hotm_uk.py check batches\r01\125.json
```

Команда покаже пропущені id, зламані `{0}`, теги та переноси ще до імпорту, тож Gemini можна одразу попросити виправити.

## 4. Імпорт

```
python hotm_uk.py import
```

Імпорт:
- бере всі нові `out\*.json`, пропускає markdown-обгортки;
- **відхиляє** рядки зі зламаними `{0}`;
- про інші проблеми (теги, переноси, пробіли) пише у звіт `batches\import_*.txt`.

Перекладені рядки отримують статус `mt` і позначку `gemini` у колонці «Перекладач».

Стан усіх батчів:

```
python hotm_uk.py batches
```
